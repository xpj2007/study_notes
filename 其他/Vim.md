**打开**： `vim 文件`

**四大模式**：

| 模式   | 功能        | 方式  |
| ---- | --------- | --- |
| 正常模式 | 移动、删除、复制  | Esc |
| 编辑模式 | 输入文本，编辑文本 | i   |
| 命令模式 | 保存、退出、替换  | v   |
| 可视模式 | 选中文本      | :   |


**常用命令和快捷键**：

| 快捷键     | 功能          |
| ------- | ----------- |
| i       | 光标前插入       |
| a       | 光标后插入       |
| I       | 行首插入        |
| A       | 行尾插入        |
| o       | 下方新开一行      |
| O       | 上方新开一行      |
| s       | 删除当前字符并插入   |
| S       | 删除整行并插入     |
| h j k l | 左 下 上 右     |
| w       | 下一个单词开头     |
| gg      | 文件开头        |
| G       | 文件末尾        |
| :n      | 跳转到第n行      |
| /word   | 向下搜索        |
| ?word   | 向上搜索        |
| x       | 删除当前字符      |
| dd      | 删除整行        |
| dw      | 删除单词        |
| ndd     | 删除n行        |
| yy      | 复制整行        |
| yw      | 复制单词        |
| u       | 撤销操作        |
| Ctrl+r  | 重做          |
| .       | 重复上一次操作     |
| v       | 进入可视模式，字符选中 |
| V       | 行选择         |
| Ctrl+v  | 列选中         |
| y       | 复制选中        |
| p       | 粘贴          |
| :w      | 保存          |
| :q      | 退出          |
| :wq     | 保存并退出       |
| :q!     | 退出不保存       |
